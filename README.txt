Olawunmi Mutiu Fakorede — Personal Academic Website
=====================================================

This package is ready for GitHub Pages.

Repository name:
    olawunmiayinde.github.io

After uploading the files to that repository:
1. Open Settings → Pages.
2. Choose Deploy from a branch.
3. Select the main branch and /(root).
4. Save.
5. Your site should publish at https://olawunmiayinde.github.io

Files:
- index.html
- styles.css
- assets/headshot.jpg
- assets/Olawunmi_Mutiu_Fakorede_CV.pdf

The website is deliberately built as a simple static site so future edits can be made
without a framework or build system.
